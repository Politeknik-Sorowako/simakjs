# PR: Implementasi KHS, Transkrip Akademik, Komponen Nilai, dan Yudisium (Issue #19)

Pull Request ini mengimplementasikan sisa use case Tahap 3 (Penutupan Semester & Evaluasi Akademik) pada Issue #19. Seluruh pengujian otomatis telah dijalankan dan berhasil lolos.

---

## 🛠️ Perubahan yang Dilakukan

### 1. Database & Skema Baru
- Menambahkan tabel `komponen_nilai` untuk konfigurasi bobot nilai per mata kuliah/kelas.
- Menambahkan tabel `nilai_komponen_mahasiswa` untuk pencatatan nilai angka per komponen.
- Menambahkan tabel `pengajuan_yudisium` untuk menyimpan administrasi kelulusan mahasiswa wisuda (Bebas Pustaka, Lab, TOEFL, TA).

### 2. Backend API
- **KHS & Transkrip**:
  - `KhsService.checkBebasTanggungan`: Blokir akses KHS jika mahasiswa memiliki tunggakan SPP semester aktif atau sisa jam kompensasi mangkir > 0.
  - Perhitungan otomatis IP Semester dan IPK Kumulatif.
- **Nilai & Evaluasi**:
  - Konfigurasi komponen nilai dosen dengan validasi total bobot wajib 100%.
  - Perhitungan otomatis Nilai Akhir (Angka, Huruf, Indeks Skala 4) di sisi server untuk menjaga integritas data.
- **Yudisium**:
  - Pengajuan yudisium bagi mahasiswa serta verifikasi administrasi dan update status kelulusan ke `lulus` oleh Admin/Kaprodi.

### 3. Frontend Portal (SolidJS)
- **Halaman Hasil Studi & KHS (`/khs`)**:
  - Tampilan KHS semester aktif dengan banner blokir bagi mahasiswa yang menunggak.
  - Tab Transkrip Nilai Kumulatif.
  - Akses detail tanpa blokir khusus untuk Dosen/Admin.
- **Halaman Evaluasi Yudisium (`/yudisium`)**:
  - Form pengisian judul TA, TOEFL, dan deklarasi bebas pinjaman bagi mahasiswa.
  - Tabel verifikasi & persetujuan yudisium bagi Admin/Kaprodi.

---

Seluruh unit & integration test pada berkas test baru `khs-yudisium.test.ts` telah lolos pengujian:
